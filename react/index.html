Write it like a note. Tasks makes it a list.

Type one line with a day, a !priority and a #list. Tasks reads it, files it and stays out of your way.

Open my list

Free, with no paywall, ever. No account needed. Works offline once installed.

It reads the line the way you wrote it.

Write the task first, then add any of these words, in any order. The same line works in the app's own add box.

friday
The day it is due: today, tomorrow or a day of the week, which means the next one.
!high
How much it matters: !high, !med or !low.
#home
The list it belongs to. A new name makes a new list.

Guest mode, the default
Your tasks are saved in this browser only. Nothing is uploaded unless you export it.
Optional Google sign-in
Signed-in tasks are stored by Google Firebase so they sync to your other devices. Only you can read them, and you can delete them and your account from inside the app.
