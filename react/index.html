Write it like a note. Tasks makes it a list.

Type one line with a day, a !priority and a #list. Tasks files it for you.

Pencil drawing: "Pay rent friday !high #home" becomes the task Pay rent, due Friday, high priority, list home.

Open my list

Free, with no paywall, ever. No account needed. After you open it once, it works offline.

It reads the line the way you wrote it.

Write the task first, then add any of these words, in any order. The same line works in the app's own add box.

friday
The day it is due: today, tomorrow or a day of the week. A day name means the next one, and today counts.
!high
How much it matters: !high, !med or !low.
#home
The list it belongs to. A new name makes a new list.

Run it from the keyboard.

Add, search, move, rename and close with keys alone. Moves and changes are announced to screen readers.

N
New task
/
Search
Ctrl K
Command menu (⌘ K on a Mac)
Alt ↑ ↓
Move a task, and hear where it went
F2
Rename
Esc
Close any panel

What other apps charge for is free here.

  • Repeating tasks that never pile up
  • Subtasks and notes

  • Light and dark themes

Where your tasks are kept.

No ads, no analytics and no third-party requests. The fonts come from this site.

Guest mode, the default
Your tasks are saved in this browser only. Nothing leaves your device. A backup is a file you save yourself.
Optional Google sign-in
Signed-in tasks are stored by Google Firebase so they sync to your other devices. Security rules let only your account read or write them, and you can delete them and your account from inside the app.
Open source, built in the open
Every line is on GitHub under the MIT license, with tests that run on every change. How AI helped, and how its work was checked, is in AI_WORKFLOW.md.
